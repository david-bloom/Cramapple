One-line: the CramApple name set in Bungee — the brand's only mark, in the four tones that cover every ground it can land on.

```jsx
<Wordmark tone="on-light" size={40} />
```

The mark is flat: no shadow, no outline, no container, never letter-spaced beyond the token, never stacked or set in two colours. On a light ground it must be `--orange-700` #ca3500 (≈5.2:1 on white) — `--orange-500` and `--orange-600` are too bright to be ink. On photography or a busy ground, use `on-dark` over a solid `--orange-600` or `--ink-900` plate rather than setting the type directly on the image.

# FRQ — Practice

The same question as Open Hand FRQ, with the scoring withheld. The left pane opens as a yellow hint gate ("Show me the rubric") over the earned/lost rule pairs; pulling it leaves a receipt that reappears in the feedback card.

Write anything in the answer field to enable the red primary action — it is desaturated, not translucent, until there is something to submit. Submitting swaps the left pane to the marked rubric (↻ for the missed point, never ✕) and the answer field to the feedback card with the submitted work kept visible beneath it.

Composes: `Plate`, `Masthead`, `Breadcrumb`, `StudyMap`, `PaneShell`, `ScoreChip`, `HintGate`, `RubricCriterionRow`, `QuestionHeader`, `GraphFrame`, `AnswerField`, `FeedbackCard`, `ActionRow`, `ActionButton`, `DeepDiveOverlay`.

# Home / study map

The one screen in the set that is not a question plate, built from the same parts: the red masthead, the breadcrumb with its ⌂ handle, and the 352 / fluid / 324 grid.

Left is the red-outlined "where you left off" card — the primary surface, carrying the one red action. Centre is the unit map: six topics with per-question progress dots and their mode. Right explains the two modes and the mark vocabulary, in the green reference voice.

This screen did not exist in the four source templates; it is assembled from their parts and content rules, and should be checked against the real product when a Home design exists.

Composes: `Plate`, `Masthead`, `Breadcrumb`, `StudyMap`, `PaneShell`, `ScoreChip`, `ActionRow`, `ActionButton`.

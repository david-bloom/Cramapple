# MCQ — Practice

One question, four options, one submission. The left pane is an Elimination hint gate: pulling "Rule out two choices" strikes A and D in clay in the question pane and leaves a receipt that reappears on the feedback card.

Submitting reveals the key, marks the student's choice with ↻ if it missed (never ✕), and drops the feedback card beneath the options with the coaching written against the wording they picked.

Composes: `Plate`, `Masthead`, `Breadcrumb`, `StudyMap`, `PaneShell`, `ScoreChip`, `HintGate`, `RadioOptionRow`, `QuestionHeader`, `FeedbackCard`, `VerdictChip`, `ActionRow`, `ActionButton`, `DeepDiveOverlay`.

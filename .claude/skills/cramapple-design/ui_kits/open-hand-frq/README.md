# Open Hand FRQ

The demonstration plate. The rubric is face-up and every point is manipulable: clicking a criterion takes the point back (✕, the teacher's hand) and the matching phrase in the credited response is struck out, so the student watches the score move with the language.

Composes: `Plate`, `PlateGrid`, `Masthead`, `Breadcrumb`, `StudyMap`, `PaneShell`, `ScoreChip`, `RubricCriterionRow`, `QuestionHeader`, `GraphFrame`, `ActionRow`, `ActionButton`, `DeepDiveOverlay`.

Interactions: toggle any rubric point · open the study map from the ⌂ handle · open the full-frame deep dive from the text link.

Content is AP Statistics 2.3 (least-squares regression), the same question as the Practice FRQ kit so the two modes can be read against each other.

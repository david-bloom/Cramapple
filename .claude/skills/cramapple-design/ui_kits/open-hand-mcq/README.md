# Open Hand MCQ

The answer key is face-up before the student picks: every option carries Correct or Distractor from the start, and the left pane counts explanations read instead of scoring. Selecting is free — it is a reading move.

Composes: `Plate`, `Masthead`, `Breadcrumb`, `StudyMap`, `PaneShell`, `RadioOptionRow`, `QuestionHeader`, `ActionRow`, `ActionButton`, `DeepDiveOverlay`.

Every distractor carries both halves of the rule: why it tempts, and the one-line fix.

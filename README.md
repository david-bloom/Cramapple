# Cramapple

Cramapple is an AP score-optimization product. The initial product focuses on AP Biology and helps students use limited study time to earn more exam points through guided topic selection, efficient instruction, targeted practice, and criterion-level feedback.

## Source of Truth

GitHub documentation in this repository is the durable project source of truth. Chat discussions are not authoritative until recorded here.

Every project document retained locally must also be committed and pushed to
this repository. Local-only documents are not durable project records.

Markdown is the canonical document format. Google Docs may be used as a
collaboration or backup copy; Word documents are exceptions for specific

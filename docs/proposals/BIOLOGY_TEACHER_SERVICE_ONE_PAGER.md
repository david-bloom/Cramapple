# Biology Teacher Service

**Status:** Draft handout for teacher feedback  
**Audience:** Biology teacher or course designer  
**Use case:** Test creation and grading for biology courses

## What this is

Cramapple can help a biology teacher build tests and grade student work with AI support.

The goal is simple:

- help you create better biology questions faster;
- help you grade responses consistently;
- keep the teacher in control of the final decision.

This is meant for biology courses first. That includes AP Biology today, and it could also fit other biology courses such as Neurobiology if the course materials are clear enough.

## What we would need from you

To make the system reliable, we would need a course packet from the teacher. The more complete the packet, the better the results.

### Minimum needed

- A course syllabus or unit outline
- The topics you actually teach
- A grading rubric, if you already use one
- A few sample questions
- A few examples of what counts as full credit, partial credit, and no credit

### Better still

- Your learning goals for each unit
- The kinds of questions you prefer
- Any required vocabulary or notation
- Any formatting rules for answers
- A few real student responses you consider representative
- Any “this is too easy,” “this is too hard,” or “this is just right” examples

### If the course is not AP Biology

We would also want:

- the official course description or standards;
- the textbook or reading list, if the class follows one;
- the scope of each unit;
- any teacher-made or department-made exam style preferences.

## What you would get back

### 1. New test questions

You could ask for a test with a difficulty mix such as:

- easy
- medium
- hard
- very hard

You could also ask for a specific number of questions, for example:

- 5 easy
- 3 medium
- 2 hard
- 1 very hard

### 2. A draft test you can review

The system would generate questions, and you would be able to review or edit them before using them with students.

### 3. Grading help

You could upload or scan completed tests, and the system would help grade them against the rubric.

It could return:

- which parts are correct;
- which parts are missing;
- where partial credit should apply;
- a total score when the rubric supports it.

### 4. Clear feedback

Instead of only giving a score, the system should explain why an answer earned credit or lost credit.

## What makes it reliable

Cramapple works best when it has:

- a clear course scope;
- a real rubric;
- a few sample questions;
- a few sample answers at different quality levels;
- a teacher review step before anything is used with students.

If the teacher only gives sample questions, the AI can still help, but the results will be less dependable.

## What Cramapple should not do

- invent course rules that the teacher did not provide;
- pretend it knows the class better than the teacher does;
- grade loosely when the rubric is unclear;
- replace teacher judgment on final test use.

## The short version

If a teacher gives Cramapple the course outline, rubric, sample questions, and sample answers, Cramapple can help create more biology tests and grade them more consistently.

If you want, I can turn your materials into a first “course packet” and then Cramapple can help from there.

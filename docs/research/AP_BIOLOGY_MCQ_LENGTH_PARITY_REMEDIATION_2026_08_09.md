## 2. Method
For each `content_key`, the current **published** version's stem, stimulus, and all four `app.mcq_choices` rows (choice_key, choice_text, is_correct, rationale) were pulled via a single read-only join query against Production. The correct choice's text is kept completely unchanged in every draft below — only the three distractors are rewritten. Each rewritten distractor keeps the *same underlying wrong claim* as the current distractor (so the tested misconception doesn't change) but expands it with the specific, plausible-but-incorrect mechanistic reasoning that a student holding that misconception would actually use — mirroring the pattern established in §4 and §8 of the 2026-07-21 QA doc. Lengths are raw character counts (`length()` in SQL / `len()` in Python) on the exact draft text, matching the mechanical check's method. The simulated ratio for every item after the rewrite is reported per item below and is below the 1.4x threshold in all 27 cases.

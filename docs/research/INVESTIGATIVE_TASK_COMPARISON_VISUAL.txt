WHAT IS AN "INVESTIGATIVE TASK"?
════════════════════════════════════════════════════════════════════════════

  AP Statistics Definition:

  A multi-part question (4–6 sub-questions) that requires students to:

  1. SPAN 2–3 CONTENT MODULES
     ✓ Not confined to single topic
     ✗ Current items mostly single-module

  2. INTEGRATE SKILLS
     ✓ Connects sampling → inference, design → testing, etc.
     ✗ Foundational items test isolated skills

  3. WORK WITH UNFAMILIAR CONTEXTS
     ✓ Requires adaptation, not routine application
     ✗ Single-question items offer no complex scenario

  4. INCLUDE MULTIPLE DECISION POINTS
     ✓ "Which test?" "Why this design?" "Is result practical?"
     ✗ Recall questions have single right answer

  5. FOLLOW A TASK ARC
     ✓ Design → Collect/Analyze → Interpret → Conclude
     ✗ "What is the median?" is a point, not an arc

From this analysis, AP Statistics Investigative Task archetype is:

  A multi-part free-response question (4–6 sub-parts, 4–5 rubric criteria)
  that integrates 2–3 content modules and requires students to apply skills
  in non-routine contexts. Task arc: Design/Context → Analysis/Calculation
  → Interpretation/Conclusion. Examples: sampling design + CI, experiment
  + hypothesis test, observational-study confounders, regression diagnostics.

  Distinguishes from:
  - Short FRQ: Single question, 1–2 criteria, isolated skill test
  - Long FRQ: Multi-part structure, 4+ criteria, cross-module integration,
             explicit real-world scenario with decision points

# FRQ-02 Audited Confirmation Run — n=40 — 2026-07-27

## Decision

Do not proceed directly to n=100 yet.

The lower-number confirmation did what it was intended to do: quality and cost
reproduced, but the speed target did not quite reproduce and tail latency was
materially worse. Run the same frozen n=40 configuration once more before
spending on n=100. This recommendation was subsequently executed; see
`RESULTS_REPEAT2_FINAL_GOLD_2026_07_27.md`.

## Frozen configuration

- Arm: `SP-FAST-Gemini-NoAudit`
- Model: `google/gemini-2.5-flash`
- Responses: deterministic original n=40 selector, including all five named
  ambiguous-cluster responses
- Criteria: 4 per response, parallel
- Boundary memory: on
- Prefilter: on
- Thinking budget: 0
- Output cap: 150 tokens
- Criterion timeout: 4,000 ms
- Escalation or post-hoc audit: none
- Cost guardrail: $0.25

This is configuration-identical to the original 146/160 Gemini result. A
separate arm name was added only to prevent the newer C2 misattribution audit
from changing the reproduction.

## Results

| Measure | Original June n=40 | 2026-07-27 n=40 | Assessment |
| --- | ---: | ---: | --- |
| Strict agreement, original labels | 146/160 (91.2%) | 145/160 (90.6%) | Reproduced within one label; above 90% |
| Strict agreement, audited labels | n/a | 151/160 (94.4%) | Above 90%; later promoted to final gold |
| Schema-valid | 160/160 (100%) | 159/160 (99.4%) | One malformed C2 response after retry |
| FRQ p50 | 935 ms | 1,041 ms | Missed 1,000 ms target by 41 ms |
| FRQ p95 | 1,224 ms | 2,411 ms | Did not reproduce; investigate variability |
| FRQ max | n/a | 3,163 ms | Below the 4-second per-criterion timeout |
| Mean estimated cost/FRQ | $0.00141 | $0.00139 | Reproduced; well below $0.01 |
| Total estimated run cost | about $0.056 | $0.05572 | Within guardrail |

Only 15/40 answers (37.5%) completed at or below 1,000 ms. There were no
timeouts. One result (`S056` / C2) remained schema-invalid after the harness's
bounded retry; treating schema failure as incorrect is why strict agreement is
145/160. Among valid model outputs, agreement with the original labels was
145/159 (91.2%).

## Accuracy by criterion

| Criterion | Original labels | Audited labels |

| C1 — identify drift/bottleneck | 39/40 (97.5%) | 40/40 (100%) |
| C2 — event-level randomness/non-selection | 32/40 (80.0%) | 33/40 (82.5%) |

| C4 — small-population mechanism | 38/40 (95.0%) | 38/40 (95.0%) |

C2 remains the limiting criterion even after label correction. Against the
audited labels, the valid-output disagreements were:

- C2: `S020`, `S023`, `S028`, `S054`, `S062`, and `S068`
- C4: `S016` and `S067`
- Schema failure: `S056` / C2

Ten of the 23 proposed audit changes occur in this n=40 sample. The model agrees
with the audited label rather than the original on eight of those ten. That
raises strict agreement by six net labels, from 90.6% to 94.4%, and is evidence
that the source-label problem was material. The corrections were subsequently
promoted to final gold by explicit repository-owner direction.

## Audit result

All 100 responses and 400 criterion labels were reviewed. The original JSONL
was preserved. The separate overlay adjudicates:

- 17 C2 changes from `earned` to `not_earned`
- 5 C3 changes from `not_earned` to `earned`
- 1 C1 change from `earned` to `not_earned`
- no C4 changes

The dominant failure mode is systematic: labels often treat random
allele-frequency change after the bottleneck as if it proved that the event
itself randomly selected survivors. Those are distinct rubric boundaries.

## Recommended next step

1. Repeat the frozen no-audit n=40 run once, using the same response IDs and a
   fresh raw-output file. Do not tune the prompt between runs.
2. Advance to n=100 only if the repeat remains at or above 90% against the
   adjudicated labels and the latency distribution establishes that the
   1,041-ms p50 was run variance rather than a persistent regression.
3. If p50 again exceeds 1,000 ms or p95 remains near 2.4 seconds, investigate
   gateway/provider latency before expanding sample size. The next experiment
   should target speed, not another rubric or routing variant.

The repeat remained above 90% but missed the speed target again, so item 3 is
now the active recommendation.

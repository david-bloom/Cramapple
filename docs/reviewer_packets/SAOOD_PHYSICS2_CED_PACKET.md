# Saood Review Packet — AP Physics 2 (2026-27 CED Update)

**Why you're getting this:** AP Physics 2's official Course and Exam Description was substantially restructured for 2024-25. Use this as your scope reference whenever you're reviewing `apphy2-*` items, alongside the full fact pack in Drive ("AP Physics 2 2026-27 — CED Fact Pack (v3, primary source, use this one — v2 was a placeholder error)").

## What changed

1. **Fluids has been removed from AP Physics 2 entirely.** It's now part of AP Physics 1 (Unit 8) instead. If you see any `apphy2-*` item testing fluids/buoyancy/pressure/Bernoulli's principle, flag it — it's out of scope for this course now.
2. Units renumbered 9-15 (was 1-7).
3. Optics is now split into two units instead of one combined unit: Unit 13 Geometric Optics (mirrors, lenses, reflection, refraction) and Unit 14 Waves, Sound, and Physical Optics (interference, diffraction, Doppler, EM waves). When checking topic placement, don't conflate the two.

## What to do when reviewing

- If an item's content is scientifically correct but tests fluids, flag it for retirement/reassignment rather than approving — it's a scope violation, not a content error.
- Everything else (thermo, E&M, optics, modern physics) is still valid Physics 2 territory; the physics itself didn't change, only the fluids removal and the optics-unit split.
- If you're unsure whether something belongs in Physics 1 or Physics 2 now, flag it in your review notes rather than guessing — David will confirm placement.

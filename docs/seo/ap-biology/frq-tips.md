# AP Biology FRQ Tips: How to Write Answers That Score

AP Biology FRQs reward precision. The question is not whether you know the topic. The question is whether you can answer in the exact way the rubric asks for.

## What the task words mean

| Task Word | What It Means |
|---|---|
| Describe | State what is there |
| Explain | Show the mechanism |
| Justify | Make the claim and support it |
| Predict | State the likely outcome |
| Design | Identify variables, controls, and measurable outcomes |

## What strong FRQ answers do

- Name the correct concept.
- Explain the causal chain.
- Connect the answer to the prompt.
- Include the specific evidence or control the rubric requires.

## What weak FRQ answers do

- Say the right general idea but skip the mechanism.
- Use vague words like "affects" or "helps" without explanation.
- Answer the topic instead of the question.
- Miss the control, variable, or data connection.

## How to study FRQs

1. Read the prompt and identify the task word.
2. Underline the exact thing being asked.
3. Write one sentence per criterion.
4. Check whether each sentence earns a point.
5. If a point is missing, repair only that gap.

## Why this matters

Students often know the biology but lose points because the answer is incomplete. The best FRQ prep is not more words. It is more point-aware words.

## Answer key and scoring guidance

### MCQ key

1. A — For x≠2, (x²−4)/(x−2)=x+2, so the limit is 4.

2. B — Continuity requires 2k+1=2²−1=3, so k=1.

3. C — Because 0 lies between −2 and 5, the Intermediate Value Theorem guarantees f(c)=0 for some c in (1,4).

4. D — The numerator and denominator have equal degree, so the limit is the ratio 5/2=2.5 of leading coefficients.

5. A — The derivative at a is lim(h→0)[f(a+h)−f(a)]/h; set a=3.

6. B — f′(x)=2xe^x+x²e^x, so f′(1)=3e.

7. C — The product rule gives (sec x tan x)tan x+sec x(sec²x)=sec x(tan²x+sec²x).

8. D — Differentiability at a point implies continuity at that point.

9. A — The chain rule gives cos(x²)·2x.

10. B — Implicit differentiation gives 2x+2yy′=0, so y′=−x/y=−3/4.

11. C — v(t)=3t²−9.4t+2.1, and v(2.35)=−3.4225≈−3.42 meters per second.

12. D — dA/dt=2πr·dr/dt=2π(5.2)(0.37)≈12.1 square centimeters per minute.

13. A — L(x)=2+(1/4)(x−4), so L(4.1)=2.025.

14. B — L'Hospital's Rule gives lim(x→0)2e^(2x)=2.

15. C — f′(x)=3x²−3=3(x−1)(x+1), so the critical numbers are −1 and 1.

16. D — The average rate is (9−1)/(3−1)=4. Since f′(x)=2x, c=2.

17. A — The derivative zeros are approximately −0.910, 0.796, and 3.313; f′ changes from positive to negative at x≈−0.910.

18. B — Concavity is upward where f″(x)>0, so 6x−12>0 and x>2.

19. C — If the sides are x and 10−x, area x(10−x) is maximized at x=5, giving 25.

20. D — The right sum is 0.7(2.8)+1.2(1.6)+1.1(3.4)=7.62.

21. A — The Fundamental Theorem and chain rule give F′(x)=√(1+(x²)³)·2x.

22. B — The signed areas of an odd function over a symmetric interval cancel.

23. C — With u=x² and du=2x dx, the integral is sin(x²)+C.

24. D — The average value is (1/1.6)∫₀^1.6 e^(−x²)dx≈0.541.

25. A — y(0.5)=1+0.5(1)=1.5 and y(1)=1.5+0.5(0.5+1.5)=2.5.

26. B — The logistic growth rate as a function of P is a downward-opening quadratic with maximum at half the carrying capacity, P=450.

27. C — The area is ∫₀¹(x−x²)dx=1/2−1/3=1/6.

28. D — The disk-method volume is π∫₀^1.3 e^(−2x²)dx≈1.951.

29. A — Displacement is ∫₀^2.2[sin(t²)+0.5]dt≈1.719 meters.

30. B — Arc length is ∫₀^1.4√(1+4x²)dx≈2.520.

## Answer key and scoring guidance

### MCQ key

1. C — L'Hospital's Rule or the standard exponential limit gives lim(x→0)3e^(3x)=3.

2. B — Using standard limits, ln(1+2x) is asymptotic to 2x and sin(3x) to 3x, so the limit is 2/3.

3. C — The product rule gives f′(x)=2xln x+x, so f′(1)=1.

4. D — The derivative definition applied to f′ at x=2 is lim(h→0)[f′(2+h)−f′(2)]/h.

5. A — The chain rule gives [1/(1+(x²)²)]·2x=2x/(1+x⁴).

6. D — For an inverse function, g′(5)=1/f′(g(5))=1/f′(2)=−1/3.

7. D — From V=(4/3)πr³, dV/dt=4πr²dr/dt=4π(9)(0.2)=7.2π cubic centimeters per second.

8. C — a(t)=sin(t²)+2t²cos(t²), so a(1.3)≈0.591.

9. A — The derivative is positive outside its zeros −2 and 1, so f increases on (−∞,−2) and (1,∞).

10. C — The secant slope is e−1. Since f′(c)=e^c, the required value is c=ln(e−1), which lies in (0,1).

11. A — The derivative zeros are approximately ±0.359 and ±1.967; positive-to-negative sign changes occur at x≈−1.967 and x≈0.359.

12. D — The even-multiplicity factors do not change sign at −2 or 0; the odd factor changes f′ from negative to positive at 1, producing only a local minimum.

13. D — lim(b→∞)∫₁ᵇx⁻²dx=lim(b→∞)(1−1/b)=1.

14. A — Integration by parts gives ∫xe^x dx=xe^x−e^x+C.

15. D — Since 1/(x²−1)=1/[2(x−1)]−1/[2(x+1)], the integral is (1/2)ln|(x−1)/(x+1)|+C.

16. A — G′(x)=2x cos(x⁶), so G′(1.2)=2.4cos(1.2⁶)≈−2.371.

17. B — Integration by parts gives [−(ln x)/x]₁^∞+∫₁^∞1/x²dx=0+1=1.

18. D — The steps give y(0.25)=0.75 and y(0.5)=0.75+0.25(0.25²−0.75)=0.578125≈0.578.

19. C — The solution is P=1200/(1+3e^(−0.4t)); setting P=600 gives t=ln(3)/0.4≈2.747.

20. C — The area is ∫₀¹(√x−x)dx=2/3−1/2=1/6.

21. A — A semicircle with diameter e^(−x²) has area (π/8)e^(−2x²), so V=(π/8)∫₀^1.5e^(−2x²)dx≈0.245.

22. B — dy/dx=(3t²−3)/(2t), which equals 0 at t=1.

23. B — The velocity is ⟨2t−2,−e^(−t)⟩, so the speed at 1.4 is √(0.8²+e^(−2.8))≈0.837.

24. B — One petal is traced for 0≤θ≤π/3, so its area is (1/2)∫₀^(π/3)4sin²(3θ)dθ=π/3.

25. A — dy/dx=sin t/(1+cos t). Differentiating with respect to t and dividing by dx/dt gives d²y/dx²≈0.421 at t=1.

26. B — The geometric series has first term 5 and ratio −1/3, so its sum is 5/[1−(−1/3)]=15/4.

27. B — The alternating-series conditions hold, but Σ1/√n is a divergent p-series, so convergence is conditional.

28. C — The radius is 3. At x=5 the harmonic series diverges; at x=−1 the alternating harmonic series converges, giving [−1,5).

29. B — The next derivative has magnitude at most 1, so |R₅(0.7)|≤0.7⁶/6!≈0.000163.

30. A — Since e^(−x)=Σ(−1)^n x^n/n!, the x⁷ term after multiplying by x² comes from n=5 and has coefficient −1/5!=−1/120.

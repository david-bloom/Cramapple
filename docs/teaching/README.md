# Teaching Documents

## Canonical Sources

The Markdown files in this directory are Cramapple's durable source of truth for teaching and learning:

| Canonical file | Authority |
| --- | --- |
| `TEACHING_AND_PEDAGOGY_DESIGN.md` | Governing pedagogical principles, boundaries, and evidence standards |
| `LEARNING_SYSTEM.md` | Operational learning loop and ordinary learner experience |
| `LEARNING_SYSTEM_STUCK.md` | Escalation behavior when the ordinary learning loop is not enough |

When the documents overlap, the teaching and pedagogy design governs principles, the learning system governs the ordinary operational loop, and the stuck-state protocol governs escalation.

## Word Snapshots

The DOCX files are generated presentation snapshots for review, printing, and circulation. They are not edited as independent sources and do not override the Markdown files. If a DOCX and its Markdown source differ, the Markdown file governs.

Current snapshots:

| Canonical source | Presentation snapshot |
| --- | --- |

| `LEARNING_SYSTEM_STUCK.md` | `Cramapple-Stuck-State-and-Escalation-Protocol-v0.3.docx` |

Regenerate the corresponding DOCX after a substantive Markdown change. Superseded snapshots remain available in Git history rather than in the active teaching directory.

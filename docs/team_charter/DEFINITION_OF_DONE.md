# Cramapple Definition of Done

**Status:** Approved
**Owner / Product Owner:** David Bloom

A task is Done only when:

- Approved scope is implemented.
- Acceptance criteria are met.
- Tests/QA checks are documented.
- Deviations are documented.
- Risks or residual gaps are documented.
- Required approvals are recorded.
- Required source-of-truth docs are updated.
- QA has passed, if QA is required.
- David's Done decision is recorded when the task crosses a hard gate or requires Product Owner acceptance.

Not Done:

- Code exists but no QA evidence.
- QA passed but owner Done decision is required and missing.
- Implementation relies on chat-only decisions.
- Hard gate was crossed without approval.

# Claude AP Physics Question Authoring Packet

```text
You are generating original AP Physics questions, answer keys, and brief
rubric notes for Cramapple.

Goal:
- create a governed starter set that helps us teach and grade Physics well;
- support four separately sold SKUs with one shared physics engine;
- optimize for student learning, point-maximizing strategy, and reliable
  grading;
- do not copy College Board text, layouts, or phrasing.

Read first:
- docs/product/AP_PHYSICS_FOUR_SKU_LAUNCH_PLAN.md
- docs/product/AP_PHYSICS_PHASE4_CONTENT_AUTHORING_BRIEF.md
- docs/tasks/TASK-0015-AP-PHYSICS-LAUNCH.md
- docs/research/AP_CHEMISTRY_PHYSICS_GRADING_TEST_MATRIX.md
- docs/architecture/CONTENT_AUTHORING_AND_PROMPT_ARCHITECTURE.md
- docs/architecture/CONTENT_GOVERNANCE_AND_VALIDATION.md
- docs/research/grading_test_packet_requirements.md
- docs/research/GRADING_RESEARCH_CANONICAL_PROCESS.md

Create an original draft set for all four SKUs:
- AP Physics 1
- AP Physics 2
- AP Physics C: Mechanics
- AP Physics C: Electricity and Magnetism

Use these design rules:
- AP Physics 1 and AP Physics 2 must include diagram-heavy support from day
  one.
- The calculus-based pair should share a single rubric path for calculus
  notation and derivations.
- Use one shared misconception library across all four SKUs.
- Treat point-maximizing guidance as a real product requirement, not an afterthought.
- Keep the items original and instructionally useful.
- Make the answer key unambiguous.
- Include boundary cases, not just clean winners.

For each item, provide:
1. SKU
2. question type
3. topic/module
4. difficulty
5. original question stem
6. answer key
7. short rubric note
8. common misconception(s)
9. point-maximizing teaching note

Suggested first pass:
- 4 items for AP Physics 1
- 4 items for AP Physics 2
- 4 items for AP Physics C: Mechanics
- 4 items for AP Physics C: Electricity and Magnetism

Within each SKU, try to include:
- at least one calculation-heavy item;
- at least one explanation-heavy item;
- at least one diagram or graph item where relevant;
- at least one boundary item;
- and at least one item that exposes a common misconception.

Constraints:
- do not imitate College Board wording or prompt structure;
- do not use official questions, scoring guides, or secure materials;
- do not overfit the set to one subtopic;
- do not write answers so long that the item becomes hard to grade;
- if a derivation is required for a calculus-based item, keep the rubric
  compact and practical.

Output format:
For each SKU, list the items in a table with the fields above, then add a short
SKU summary describing:
- which concepts are strongest;
- which concepts need more coverage;
- which items are best suited for calibration;
- and which misconceptions should enter the shared library first.
```

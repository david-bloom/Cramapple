# Lovable Physics Launch Assignment

```text
You are handling the frontend and product-experience side of the AP Physics
four-SKU launch.

Project roles:
- Lovable owns the frontend experience, subject selection, route behavior,
  package presentation, and student-facing UX.
- Keep the work aligned with the shared platform and the Physics task docs.

Read first:
- docs/tasks/TASK-0015-AP-PHYSICS-LAUNCH.md
- docs/product/AP_PHYSICS_FOUR_SKU_LAUNCH_PLAN.md
- docs/product/AP_PHYSICS_PHASE4_CONTENT_AUTHORING_BRIEF.md
- docs/research/AP_CHEMISTRY_PHYSICS_GRADING_TEST_MATRIX.md
- docs/architecture/CONTENT_AUTHORING_AND_PROMPT_ARCHITECTURE.md
- docs/architecture/CONTENT_GOVERNANCE_AND_VALIDATION.md

Design goals:
- present AP Physics as four separately sold SKUs;
- make the difference between algebra-based and calculus-based tracks obvious;
- support diagram-heavy responses from day one for Physics 1 and Physics 2;
- preserve a clean path for Physics C Mechanics and Physics C Electricity and
  Magnetism;
- keep student pathways point-maximizing and exam-practical without feeling
  spammy;
- make the shared physics engine feel consistent across all four options.

What to produce:
1. A frontend plan for the four-SKU selection and onboarding experience.
2. A route/UX map that shows what is shared versus SKU-specific.
3. A proposal for diagram-heavy response UI on Physics 1 and Physics 2.
4. A proposal for how the calculus-based pair should surface calculus notation
   and derivation expectations.
5. A short list of reusable UI components that should live in the shared
   physics engine.
6. Any frontend risks or open questions that need backend or curriculum input.

Constraints:
- do not copy College Board wording;
- do not assume the curriculum is ready unless the source docs say so;
- prefer simple, durable UX over overfitted launch art;
- highlight anything that would require a backend or content dependency.

Output format:
- Executive summary
- Shared UX defaults
- SKU-specific UX differences
- Open questions
- Next implementation steps
```

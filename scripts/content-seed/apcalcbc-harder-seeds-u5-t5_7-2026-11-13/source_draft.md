## Seed N-5.7-A (new) — Topic 5.7 Using the Second Derivative Test

**Skill:** differentiate a factored first derivative and classify two critical points



A twice-differentiable function f has f'(x)=1(x−(-2))(x−(1)) on an interval containing both zeros, with -2<1. What does the second derivative test establish at the two critical points?



- **A. A local maximum at x=-2 and a local minimum at x=1.**

- B. A local minimum at x=-2 and a local maximum at x=1.

- C. Both zeros are local minima because f' is zero at each.

- D. The test is inconclusive at both points because f'' is not given directly.



Check: Differentiating gives f''(x)=1(2x−(-2)−(1)). Thus f''(-2)=-3 and f''(1)=3; their opposite signs classify the two extrema.

Rationales: B: This reverses the signs of f'' at the two critical points. C: A zero of f' only identifies a candidate; the opposite second-derivative signs yield opposite types. D: f'' can be calculated by differentiating the given f', so the test is conclusive at both points.

## Seed N-5.7-B (new) — Topic 5.7 Using the Second Derivative Test

**Skill:** handle an inconclusive zero second derivative with independent evidence



For g(x)=1(x−(1))^4, a student finds g'(1)=0 and g''(1)=0. Which conclusion is justified about x=1, and why is the second derivative test alone insufficient?



- **A. x=1 is a local minimum; the even power and positive coefficient make g(x) greater than g(a) on both sides, while g''(1)=0 makes the second derivative test inconclusive.**

- B. x=1 must be a local minimum because g''(1)=0 and zero counts as nonnegative.

- C. x=1 must be a local maximum because g'(1)=0 and g''(1)=0.

- D. No conclusion about the actual function can be drawn by any method because the second derivative test is inconclusive.



Check: At x=1, the first two derivatives vanish. The sign of 1(x−(1))^4 relative to g(1)=0 on either side shows minimum; zero second derivative alone does not classify it.

Rationales: B: The test requires a strictly positive second derivative for a minimum; zero is inconclusive. C: Vanishing first and second derivatives do not establish a maximum; inspect the function or derivative sign. D: An inconclusive test does not prohibit using the function's explicit power and sign to classify the point.

## Seed N-5.7-C (new) — Topic 5.7 Using the Second Derivative Test

**Skill:** connect a conclusive second derivative test and a unique critical point to global behavior



A continuous function h is differentiable for every real x and has h'(x)=1(x−(-2))/(1+x²). This is its only critical point. What can be concluded about x=-2 using the second derivative test together with the one-critical-point result?



- **A. h has a local minimum at x=-2, and it is also an absolute minimum on the real line.**

- B. h has a local maximum at x=-2, and it is also an absolute maximum because the denominator is positive.

- C. h has a local minimum at x=-2, but it cannot be an absolute extremum because the real-line interval has no endpoints.

- D. h has no extremum at x=-2 because the first derivative vanishes there.



Check: h''(-2)=1/(1+-2²), with sign positive. The denominator of h' is always positive, so h' changes negative to positive at its unique zero; the local minimum is absolute.

Rationales: B: The sign of h'' at the critical point is reversed here, so the local type is wrong. C: A continuous function with only this critical point and a local extremum has the same absolute extremum on its real-line domain; endpoints are not required. D: A zero first derivative is a critical point, and the nonzero second derivative classifies an extremum.

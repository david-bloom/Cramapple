## 3.8 Representations of Solutions

**Know: core_idea**
```
- A particulate diagram shows relative particle numbers and the solute-solvent interactions drawn.
- Compare two diagrams' concentrations only after allowing for box size.
- Not tested: colligative properties; molality or percent-by-mass/volume calculations.
```

**Know: mechanism (what_students_need_to_understand)**
```
Concentration is particles per unit volume:

| Boxes drawn | Compare by |
| Equal volume | Particle counts directly |
| Unequal volume | Particles ÷ box size (area, in 2-D) |
```

**Score: steps (how_this_becomes_points)**
```
1. Check whether the boxes represent equal volumes; if not, divide each particle count by its box size.
2. Compare particles per unit volume.
3. State the conclusion as concentration, not raw count.
```

## 3.9 Separation of Solutions and Mixtures

**Know: core_idea**
```
- Filtration separates a solid suspended in a liquid; dissolved solute passes through with the solvent.
- Components of a liquid solution can be separated by exploiting differences in intermolecular interactions.
- Chromatography: stationary phase (surface) and mobile phase (solution).
```

**Know: mechanism (what_students_need_to_understand)**
```
Distance travelled follows interaction strength:

| Component interacts more strongly with | Travels |
| Mobile phase | Farther |
| Stationary phase | Less far |
```

**Score: steps (how_this_becomes_points)**
```
1. Decide the mixture type: a solid suspended in liquid (filtration works) or a dissolved solution (it does not).
2. For chromatography, name both phases and which component interacts more strongly with each.
3. Explain distance by interaction strength and infer relative polarity; never by size or mass.
```

**Score: Weak (common_point_loss)**
```
Weak: “Dye A must have a smaller molar mass than Dye B, since it can travel farther and faster.” It breaks step 3: distance reflects interaction strength with the phases, not mass.
```

**Score: Full credit (answer_move)**
```
Full credit: (1) Both dyes are dissolved in one liquid phase, so filtration cannot separate them. (2) The paper is polar and the solvent nonpolar; Dye A partitions more into the nonpolar solvent, Dye B interacts more with the polar paper. (3) A travels farther because of differential interaction strength, so A is less polar and B more polar.
```

## 3.10 Solubility

**Know: core_idea**
```
- Substances with similar dominant intermolecular forces tend to be soluble or miscible in one another.
- Forces to name: London dispersion, dipole-dipole, hydrogen bonding, ion-dipole.
```

**Know: mechanism (what_students_need_to_understand)**
```
Why a match or mismatch matters:

| Forces | Effect |
| Match | Solvent particles can replace the solute's own interactions |
| Mismatch | Solvent–solute attractions replace the disrupted interactions poorly |
```

**Score: steps (how_this_becomes_points)**
```
1. Name the dominant force in the solute and in the solvent.
2. State whether they match.
3. Predict solubility or miscibility from the match; do not cite “like dissolves like” alone.
```

**Score: Weak (common_point_loss)**
```
Weak: “Like dissolves like, so iodine dissolves better in hexane than in water.” It skips steps 1 and 2: no force is named and no match is stated.
```

**Score: Full credit (answer_move)**
```
Full credit: (1) I₂ is nonpolar, so London dispersion only; hexane: London dispersion; water: hydrogen bonding. (2) I₂ and hexane match; I₂ and water mismatch, since I₂–water attractions would replace water's hydrogen bonds poorly. (3) So iodine dissolves readily in hexane and is only slightly soluble in water.
```

## 3.11 Spectroscopy and the Electromagnetic Spectrum

**Know: core_idea**
```
- Energy order: microwave < infrared < UV/visible.
- A band shows only its own region's transition type; it does not by itself show the others.
```

**Know: mechanism (what_students_need_to_understand)**
```
| Region | Transition | A band shows |
| Microwave | Rotational | Molecular rotation |
| Infrared | Vibrational | Bond stretching or bending |
| UV/visible | Electronic | An electron changing energy level |
```

**Score: steps (how_this_becomes_points)**
```
1. Read the spectral region the prompt gives.
2. Match it to its one transition type.
3. Draw only conclusions of that type; claims about electronic energy levels need UV/visible.
```

## 3.12 Properties of Photons

**Know: core_idea**
```
- c = λν: shorter wavelength, higher frequency.
- E = hν: higher frequency, greater photon energy.
- So shorter wavelength means greater photon energy.
```

**Know: mechanism (what_students_need_to_understand)**
```
What a photon does to the species:

| Process | Species' energy |
| Absorbs a photon | Rises by the photon energy |
| Emits a photon | Falls by the photon energy |
```

**Score: steps (how_this_becomes_points)**
```
1. Identify whether wavelength, frequency or energy is given; convert wavelength to metres before calculating.
2. Chain c = λν into E = hν, using only as much as needed.
3. Say which energy change the result stands for.
```

**Score: Weak (common_point_loss)**
```
Weak: “The 700 nm photon has more energy because the wavelength number is larger.” It breaks step 2: a longer wavelength means a lower frequency, and energy follows frequency.
```

**Score: Full credit (answer_move)**
```
Full credit: (1) Wavelengths are given: 400 nm is shorter than 700 nm. (2) Shorter wavelength gives higher frequency (ν = c/λ), so more energy (E = hν). (3) The 400 nm photon carries more energy, so if absorbed it raises the species' energy by more; compare frequency and energy, not the size of the wavelength number.
```

## 3.13 Beer-Lambert Law

**Know: core_idea**
```
- A = εbc: absorbance = molar absorptivity × path length × concentration.
- With wavelength and path length fixed, A is proportional to concentration.
```

**Know: mechanism (what_students_need_to_understand)**
```
What changes absorbance:

| Change | Effect on A |
| Concentration ×2 | ×2 (ε and b fixed) |
| Path length ×2 | ×2 (ε and c fixed) |
| Wavelength | ε changes, so do not compare directly |
```

**Score: steps (how_this_becomes_points)**
```
1. Note what is held constant: the compound and wavelength (ε) and the path length (b).
2. If both are constant, compare concentrations by comparing absorbances.
3. Read higher absorbance as more absorber in the light path, not as a higher photon energy.
```

**Score: Weak (common_point_loss)**
```
Weak: “The second solution absorbed twice as much light, so its photons must have twice the energy.” It breaks step 3: absorbance tracks the amount of absorber; the wavelength, and so the photon energy, did not change.
```

**Score: Full credit (answer_move)**
```
Full credit: (1) Same compound, wavelength and 1.00 cm path, so ε and b are constant. (2) A ∝ c, so 0.80 ÷ 0.40 = 2: the concentration doubled. (3) Photon energy is unchanged; more absorbing species lies in the path.
```

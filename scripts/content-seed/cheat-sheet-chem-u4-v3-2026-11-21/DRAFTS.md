## 4.1 Introduction for Reactions

**Know: core_idea**
```
- Chemical change: new substances form, typically with different compositions.
- Physical change: state, form or mixture changes; the substances stay the same.
- Possible evidence of chemical change: heat or light, gas, precipitate, color change.
```

**Know: mechanism (what_students_need_to_understand)**
```
- Chain of reasoning: observation → composition changed → particles rearranged into different substances.
- A cue alone is not the definition: a phase or temperature change by itself does not show new substances.
```

**Score: steps (how_this_becomes_points)**
```
1. State whether composition changes.
2. Name the observation that supports it.
3. Say what happened to the substances, not just how it looked.
```

**Score: Weak (common_point_loss)**
```
Weak: “It is a chemical reaction because the mixture changed color and looked different.” It skips steps 1 and 3: it describes the look, never whether new substances formed.
```

**Score: Full credit (answer_move)**
```
Full credit: (1) A solid forming points to a composition change. (2) The precipitate is the evidence. (3) Ions in solution rearranged to form a new insoluble substance, so the observation supports new substances, not merely a different look.
```

## 4.2 Net Ionic Equations

**Know: core_idea**
```
- Three forms of one reaction: molecular, complete ionic, net ionic.
- Complete ionic equation: strong aqueous electrolytes written as ions, with phases.
- Net ionic equation: only the species that change; atoms and total charge still balance.
```

**Know: mechanism (what_students_need_to_understand)**
```
Decide species by species:

| Species | In the net ionic equation |
| Same formula, charge and phase on both sides | Cancel (spectator) |
| Changes phase, formula or charge | Keep |
```

**Score: steps (how_this_becomes_points)**
```
1. In the complete ionic equation (strong aqueous electrolytes as ions, with phases), cancel only species identical on both sides in formula, charge and phase.
2. Check that atoms and total charge balance in what remains.
```

**Score: Weak (common_point_loss)**
```
Weak: “Keep Na⁺ because every ion in the solution should appear in the final equation.” It breaks step 1: Na⁺(aq) is identical on both sides, so it is a spectator and cancels.
```

**Score: Full credit (answer_move)**
```
Full credit: (1) Na⁺(aq) is identical on both sides (same charge, aqueous phase), so it is a spectator and cancels. (2) The net ionic equation keeps the species that react or change phase, and atoms and total charge must still balance.
```

## 4.3 Representations of Reactions

**Know: core_idea**
```
- Coefficients are particle ratios; the same atoms (and charge) appear before and after.
- Any form of a balanced equation can be translated into one consistent particulate model.
- Reactants are drawn before the change, products after.
```

**Know: mechanism (what_students_need_to_understand)**
```
Spectator ions depend on the representation:

| Representation | Spectator ions |
| Complete particulate | May be shown |
| Net ionic | Omitted |
```

**Score: steps (how_this_becomes_points)**
```
1. Read the coefficients as a particle ratio.
2. Draw reactants and products in that ratio, or a consistent multiple, with formulas and charges matching the equation.
```

**Score: Weak (common_point_loss)**
```
Weak: “It can show one AgNO₃ particle because coefficients only balance the written equation.” It breaks step 1: a coefficient of 2 is a particle ratio, not just bookkeeping.
```

**Score: Full credit (answer_move)**
```
Full credit: (1) The coefficient 2 on AgNO₃ and 1 on the product make a 2 : 1 ratio. (2) The diagram must show two AgNO₃ formula units (or the ions they supply) for every one product unit, or a consistent multiple of that.
```

## 4.4 Physical and Chemical Changes

**Know: core_idea**
```
- Ask what changes at the particle level, not for a one-word rule.
- Intermolecular attractions usually change in physical changes; chemical bonds usually change in chemical changes.
```

**Know: mechanism (what_students_need_to_understand)**
```
| Process | What changes | Composition |
| Melting ice | Intermolecular attractions | Unchanged (still H₂O) |
| Reaction forming new covalent or ionic substances | Chemical bonds | Changes |
| Dissolving an ionic solid | Ionic attractions and ion-dipole interactions | Needs a careful argument |
```

**Score: steps (how_this_becomes_points)**
```
1. Name the interaction broken or formed.
2. Tie it to composition: no change means physical, a change means chemical.
```

**Score: Weak (common_point_loss)**
```
Weak: “Chemical, because bonds are broken when the solid structure falls apart.” It breaks step 1: melting ice weakens intermolecular attractions, not the bonds inside the molecules.
```

**Score: Full credit (answer_move)**
```
Full credit: (1) Melting ice weakens intermolecular attractions and changes the particle arrangement. (2) The molecules remain H₂O, so composition is unchanged and it is a physical change.
```

## 4.5 Stoichiometry

**Know: core_idea**
```
- Stoichiometry is conservation of atoms turned into calculation.
- Balanced coefficients are mole ratios, not mass ratios.
- Mass, gas volume or solution data must become moles before the equation is used.
```

**Know: mechanism (what_students_need_to_understand)**
```
| Quantity | To moles | From moles |
| Mass | ÷ molar mass | × molar mass |
| Gas | n = PV/RT | V = nRT/P |
| Solution | n = M × V (L) | V = n ÷ M |
```

**Score: steps (how_this_becomes_points)**
```
1. Convert the given quantity to moles.
2. Apply the coefficient ratio (wanted ÷ given); identify the limiting reactant first if amounts of several reactants are given.
3. Convert moles to the requested unit; stop at moles only if moles were asked.
```

**Score: Weak (common_point_loss)**
```
Weak: “Yes. More moles of Zn means the mass change for Zn must be greater.” It stops at step 2: a mole ratio is not a mass comparison.
```

**Score: Full credit (answer_move)**
```
Full credit: (1) The amounts are already in moles: 3 mol Zn, 2 mol Al. (2) That ratio compares moles only. (3) Mass = moles × molar mass, so compare 3 mol × M(Zn) with 2 mol × M(Al); 3 > 2 alone does not decide it.
```

## 4.6 Introduction to Titration

**Know: core_idea**
```
- Titrant: solution of known concentration, added from a measured volume.
- Analyte: the species whose amount is found, through a specific balanced reaction.
```

**Know: mechanism (what_students_need_to_understand)**
```
| Term | What it is |
| Equivalence point | Stoichiometric: the analyte is totally consumed by the titrant |
| Endpoint | Observed: the indicator or instrument change that signals it; may only approximate equivalence |
```

**Score: steps (how_this_becomes_points)**
```
1. Titrant moles = M × V (L); the balanced mole ratio at equivalence gives analyte moles; divide by analyte volume for concentration.
2. Name the endpoint as the observed signal, which may only approximate equivalence.
```

**Score: Weak (common_point_loss)**
```
Weak: “They are the same because color change defines when all analyte is gone.” It breaks step 2: the color change is only the observed endpoint, a signal chosen to be close to equivalence.
```

**Score: Full credit (answer_move)**
```
Full credit: (1) Titrant moles come from M × V; the mole ratio at equivalence turns them into analyte moles, the stoichiometric point where the analyte is consumed. (2) The endpoint is the observed color change used to signal that point, chosen to be close to equivalence.
```

## 4.7 Types of Chemical Reactions

**Know: core_idea**
```
- Acid-base: H⁺ transfer. Redox: electron transfer. Precipitation: an insoluble or sparingly soluble ionic product forms.
- Combustion (reaction with O₂) is a redox subclass; complete hydrocarbon combustion gives CO₂ and H₂O.
- Always soluble: salts of Na⁺, K⁺, NH₄⁺, NO₃⁻.
```

**Know: mechanism (what_students_need_to_understand)**
```
Look for the signature:

| Evidence | Supports |
| H⁺ transferred | Acid-base |
| Oxidation numbers change | Redox |
| Solid ionic product from mixed aqueous ions | Precipitation (redox only if oxidation numbers also change) |
```

**Score: steps (how_this_becomes_points)**
```
1. Find the signature: H⁺ transfer, oxidation-number change, CO₂ and H₂O from a hydrocarbon burning, or a solid from mixed ions.
2. Check it against the formulas (oxidation numbers, the always-soluble ions), then name the type and cite that evidence.
```

**Score: Weak (common_point_loss)**
```
Weak: “It must be redox because a new solid formed from ions.” It breaks step 2: no oxidation-number change is shown, and solid formation alone is not electron transfer.
```

**Score: Full credit (answer_move)**
```
Full credit: (1) Mixing aqueous ions gives a solid product, the precipitation signature. (2) That supports a precipitation reaction; calling it redox would need evidence of oxidation-number changes.
```

## 4.8 Introduction to Acid-Base Reactions

**Know: core_idea**
```
- Brønsted-Lowry acid: H⁺ donor. Base: H⁺ acceptor.
- Water can donate or accept H⁺, so it can be the acid or the base.
- Outside this topic: Lewis acid-base ideas.
```

**Know: mechanism (what_students_need_to_understand)**
```
Track the transferred proton(s); name each species by what it does to H⁺:

| Species | H⁺ | Becomes |
| Acid | Loses | Conjugate base |
| Base | Gains | Conjugate acid |
```

**Score: steps (how_this_becomes_points)**
```
1. Draw an arrow for the H⁺ transfer: which species loses it, which gains it.
2. Label the donor as acid and the acceptor as base, and pair each with its conjugate.
```

**Score: Weak (common_point_loss)**
```
Weak: “H₂O is the base because it contains oxygen and becomes OH⁻.” It breaks step 1: it never tracks H⁺; H₂O loses H⁺ to become OH⁻, so it is the acid here.
```

**Score: Full credit (answer_move)**
```
Full credit: (1) NH₃ gains H⁺ from water and becomes NH₄⁺. (2) NH₃ is the base (NH₄⁺ is its conjugate acid); water donates H⁺, so it acts as the acid in this direction (OH⁻ is its conjugate base).
```

## 4.9 Oxidation-Reduction Reactions

**Know: core_idea**
```
- Redox is electron transfer from the species oxidized to the species reduced.
- Oxidation numbers identify which is which.
- Balanced redox equations conserve atoms and charge.
```

**Know: mechanism (what_students_need_to_understand)**
```
| Half-reaction | Oxidation number | Electrons appear |
| Oxidation | Increases | As products |
| Reduction | Decreases | As reactants |
```

**Score: steps (how_this_becomes_points)**
```
1. Assign oxidation numbers; identify what is oxidized and what is reduced.
2. Write each half-reaction with electrons on the correct side.
3. Check atoms and charge; to combine half-reactions, scale them so electrons cancel.
```

**Score: Weak (common_point_loss)**
```
Weak: “Electrons should be reactants because aluminum needs electrons to become positive.” It breaks steps 1 and 2: Al goes from 0 to +3, which is loss of electrons, so they belong on the product side.
```

**Score: Full credit (answer_move)**
```
Full credit: (1) Al goes from 0 to +3, so Al is oxidized. (2) Al(s) → Al³⁺(aq) + 3e⁻, with electrons as products. (3) Charge balances: 0 = +3 + 3(−1).
```

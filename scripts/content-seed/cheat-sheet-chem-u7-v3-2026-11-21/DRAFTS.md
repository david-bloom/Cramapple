## 7.1 Introduction to Equilibrium

**Know: core_idea**
```
- Dynamic equilibrium: forward and reverse processes continue at equal rates, so amounts stay constant.
- Examples: evaporation and condensation, dissolution and precipitation, proton transfer, electron transfer.
```

**Know: mechanism (what_students_need_to_understand)**
```
Reading approach-to-equilibrium graphs:

| Graph | At equilibrium |
| Concentration or partial pressure vs. time | Curves level off to constant values |
| Rate vs. time | Forward and reverse rates meet and stay equal |
```

**Score: steps (how_this_becomes_points)**
```
1. Name the forward and reverse processes.
2. State that their rates are equal.
3. Say both continue; never say the reaction stopped.
```

**Score: Weak (common_point_loss)**
```
Weak: “Yes, because the amount of vapor is no longer changing.” It skips steps 2 and 3: a constant amount is read as no change, and no rates are compared.
```

**Score: Full credit (answer_move)**
```
Full credit: No. (1) Evaporation and condensation both occur. (2) Their rates are equal. (3) Both continue, so the vapor amount stays constant.
```

## 7.2 Direction of Reversible Reactions

**Know: core_idea**
```
- Direction comes from comparing the forward and reverse rates (or Q with K), not from which side has more.
- The shift continues until the two rates are equal.
```

**Know: mechanism (what_students_need_to_understand)**
```
| Rates now | Net change | Product amount |
| Forward > reverse | Reactants to products | Increases |
| Reverse > forward | Products to reactants | Decreases |
| Equal | None (equilibrium) | Constant |
```

**Score: steps (how_this_becomes_points)**
```
1. Name the net direction from which rate is larger.
2. State the ending condition: equal rates at dynamic equilibrium.
```

**Score: Weak (common_point_loss)**
```
Weak: “The reaction must already be at equilibrium because both directions exist.” It breaks step 1: having both directions does not make their rates equal; equilibrium needs equal rates.
```

**Score: Full credit (answer_move)**
```
Full credit: (1) The forward rate is larger, so there is net forward change. (2) Product increases until the forward and reverse rates become equal.
```

## 7.3 Reaction Quotient and Equilibrium Constant

**Know: core_idea**
```
- Qc, Qp and Ksp share one form: product terms over reactant terms, each raised to its coefficient.
- Solids and pure liquids are left out.
- Not tested: converting between Kc and Kp.
```

**Know: mechanism (what_students_need_to_understand)**
```
Q against K gives the net change:

| Compare | Net change |
| Q < K | Reactants consumed, products formed |
| Q > K | Products consumed, reactants formed |
| Q = K | Dynamic equilibrium |
```

**Score: steps (how_this_becomes_points)**
```
1. Cross out solids and pure liquids.
2. Write products over reactants, coefficients as exponents.
3. Compare Q with K to state the direction.
```

**Score: Weak (common_point_loss)**
```
Weak: “Yes, because AgCl is the reactant in the equation.” It breaks step 1: a solid never appears in Ksp.
```

**Score: Full credit (answer_move)**
```
Full credit: (1) AgCl(s) is a solid, so it is excluded. (2) Ksp = [Ag⁺][Cl⁻]: dissolved ions only, each with exponent 1. (3) If Q < K, net change is forward: AgCl dissolves (provided enough solid is present) until Q = K.

## 7.4 Calculating the Equilibrium Constant

**Know: core_idea**
```

- Of the initial, change and equilibrium rows, only the last goes into K.
```

**Know: mechanism (what_students_need_to_understand)**

| At equilibrium | Substitute directly into K |
| Before equilibrium | Build an equilibrium setup first, then substitute |

2. Substitute equilibrium values only into the K expression from the balanced equation.

## 7.5 Magnitude of the Equilibrium Constant

## 7.6 Properties of the Equilibrium Constant

**Know: core_idea**
```
- Reverse the reaction: K becomes 1/K.
- Multiply coefficients by c: K becomes Kᶜ.
- Add reactions: multiply their K values.
```

**Know: mechanism (what_students_need_to_understand)**
```
- K is a ratio of product terms to reactant terms, so reversing swaps them and scaling coefficients scales the exponents.
- Adding equations cancels species that appear on opposite sides and leaves the product of the K expressions, never a sum.
```

**Score: steps (how_this_becomes_points)**
```
1. Write the changed equation.
2. Name the operation: reverse, scale or add.
3. Transform K to match that exact equation.
```

**Score: Weak (common_point_loss)**
```
Weak: “K changes sign like ΔH.” It breaks step 3: K is a ratio, so reversal gives the reciprocal.
```

**Score: Full credit (answer_move)**
```
Full credit: (1) Write the reversed equation: the old products on the left, the old reactants on the right. (2) Operation: reverse. (3) K becomes 1/K; for example, K = 4 becomes 0.25.
```

## 7.7 Calculating Equilibrium Concentrations

**Know: core_idea**
```
- Q against K gives the direction: Q < K forward, Q > K reverse.
- Changes follow the balanced coefficients, and the final values must satisfy K.
```

**Know: mechanism (what_students_need_to_understand)**
```
Changes scale with coefficients, shown for A ⇌ 2B shifting forward:

| Species | Change |
| A (coefficient 1) | −x |
| B (coefficient 2) | +2x |
```

**Score: steps (how_this_becomes_points)**
```
1. Compare Q with K to pick the direction.
2. Write each change as its coefficient times x, signs set by the direction; final values must satisfy K.
```

**Score: Weak (common_point_loss)**
```
Weak: “Reverse, because Q is smaller and needs to get bigger by making reactants.” It breaks step 1: making reactants would lower Q further, so Q < K means forward.
```

**Score: Full credit (answer_move)**
```
Full credit: (1) Q < K, so the shift is forward: product terms rise relative to reactant terms until Q = K. (2) For A ⇌ 2B, A changes by −x and B by +2x.
```

## 7.8 Representations of Equilibrium

**Know: core_idea**
```
- A particle diagram gives relative counts of reactants and products before and at equilibrium.
- K is found by turning the equilibrium particle counts into the concentrations or pressures the K expression needs, in the form for the written equation.
- Equilibrium does not mean equal counts.
```

**Know: mechanism (what_students_need_to_understand)**
```
For a one-to-one equation such as A ⇌ B:

| At equilibrium the diagram shows | Likely K |
| More product particles | Greater than 1 |
| More reactant particles | Less than 1 |
```

**Score: steps (how_this_becomes_points)**

2. Relate the counts to the K expression for the written equation.
```

**Score: Weak (common_point_loss)**

**Score: Full credit (answer_move)**

## 7.9 Introduction to Le Chatelier's Principle

**Know: core_idea**
```
- A disturbance shifts the equilibrium when it makes Q differ from K, and the shift reduces its effect.
- Stresses: add or remove a species, change volume or pressure of a gas-phase system, dilute, change temperature.
- Only temperature changes K.
```

**Know: mechanism (what_students_need_to_understand)**
```
| Stress | Changes first | Shift |
| Add a species in Q | Q | Consumes what was added |
| Remove a species in Q | Q | Replaces what was removed |
| Change temperature | K | Responds to the new K |
```

**Score: steps (how_this_becomes_points)**
```
1. Name the stress.
2. State the shift that counters it.
3. Explain how the shift counters it (for an added or removed species: consumes or replaces it).
```

**Score: Weak (common_point_loss)**
```
Weak: “Toward reactants because product is lower.” It breaks step 2: the shift replaces the removed product, so it goes toward products.
```

**Score: Full credit (answer_move)**
```
Full credit: (1) Product is removed. (2) The system shifts toward products. (3) It replaces some of what was removed and moves back toward equilibrium.
```

## 7.10 Reaction Quotient and Le Chatelier's Principle

**Know: core_idea**
```
- A stress makes Q differ from K; the system shifts to restore Q = K.
- Concentration-type stresses change Q only; a temperature change changes K itself.
- At constant temperature, K is constant.
```

**Know: mechanism (what_students_need_to_understand)**
```
| Stress | Q or K | Q versus K | Shift |
| Add a reactant in Q | Q falls | Q < K | Forward |
| Add a product in Q | Q rises | Q > K | Reverse |
| Change temperature | K changes | Q ≠ new K | Until Q = new K |
```

**Score: steps (how_this_becomes_points)**
```
1. Classify the stress: does Q change, K change, or both?
2. Compare Q with K (the new K after a temperature change).
3. Predict the shift that moves Q back toward K.
```

**Score: Weak (common_point_loss)**
```
Weak: “Yes, K changes because the mixture composition changed.” It breaks step 1: composition changes Q; only temperature changes K.
```

**Score: Full credit (answer_move)**
```
Full credit: No. (1) At constant temperature K is unchanged; an added reactant that appears in Q changes Q. (2) Reactants sit in the denominator of Q, so Q falls below K. (3) The system shifts forward until Q again equals K.
```

## 7.11 Introduction to Solubility Equilibria

**Know: core_idea**
```
- Saturated solution in contact with undissolved solid: dissolution and precipitation are in equilibrium with its dissolved ions.
- Ksp is the constant for that equilibrium; the solid is not in it.
```

**Know: mechanism (what_students_need_to_understand)**
```
Exponent = coefficient of the dissolved ion:

| Dissolution | Ion exponents in Ksp |
| AgCl(s) ⇌ Ag⁺ + Cl⁻ | 1 and 1 |
| CaF₂(s) ⇌ Ca²⁺ + 2F⁻ | 1 and 2 |
```

**Score: steps (how_this_becomes_points)**
```
1. Write the dissolution equation.
2. Leave out the solid.
3. Copy each dissolved ion's coefficient as its exponent.
```

**Score: Weak (common_point_loss)**
```
Weak: “One, because F⁻ is one type of ion.” It breaks step 3: the exponent is the coefficient 2, not the number of ion types.
```

**Score: Full credit (answer_move)**
```
Full credit: (1) CaF₂(s) ⇌ Ca²⁺ + 2F⁻. (2) The solid is excluded. (3) Coefficient 2 becomes exponent 2: Ksp = [Ca²⁺][F⁻]².
```

## 7.12 Common-Ion Effect

**Know: core_idea**
```
- Common-ion effect: a salt is less soluble in a solution that already contains one of its ions.
- Removing an ion (acid consuming a basic ion such as OH⁻) can let more solid dissolve.
```

**Know: mechanism (what_students_need_to_understand)**
```
Starting from a saturated solution:

| Ion of the salt | Q versus Ksp | Result |
| Added | Q > Ksp | More solid forms |
| Removed | Q < Ksp | More solid dissolves (if solid remains) |
```

**Score: steps (how_this_becomes_points)**
```
1. Find the salt ion whose concentration the added substance changes.
2. Decide whether it is added or removed.
3. Compare Q with Ksp to say whether more solid forms or dissolves.
```

**Score: Weak (common_point_loss)**
```
Weak: “It decreases because acid is an added substance.” It breaks step 2: acid removes OH⁻; the answer names a rule, not the ion-level shift.
```

**Score: Full credit (answer_move)**
```
Full credit: (1) The affected salt ion is OH⁻. (2) Acid removes OH⁻. (3) Q falls below Ksp, so more solid dissolves and solubility increases.
```

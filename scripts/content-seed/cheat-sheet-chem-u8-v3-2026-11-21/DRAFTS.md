## 8.1 Introduction to Acids and Bases

```

- pH + pOH = 14 (pKw) holds at 25°C.

```

## 8.2 pH and pOH of Strong Acids and Bases

**Know: core_idea**
```
- Strong acids (HCl, HBr, HI, HClO₄, H₂SO₄, HNO₃) fully ionize, so treat [H₃O⁺] = initial acid concentration (a convention; H₂SO₄'s second ionization is only partial).
- Strong bases (Group I hydroxides and Group II hydroxides such as Ca(OH)₂) fully dissociate as far as they dissolve.
```

**Know: mechanism (what_students_need_to_understand)**
```
Strong base, [OH⁻] from the dissolved hydroxide concentration:

| Hydroxide | [OH⁻] |
| Group I (e.g. NaOH) | 1 × initial |
| Group II (e.g. Ca(OH)₂) | 2 × initial |
```

**Score: steps (how_this_becomes_points)**
```
1. Use full dissociation to get [H₃O⁺] or [OH⁻].
2. Take −log to get pH (acid) or pOH (base).
3. Convert if the prompt asks for the other (25°C: pH + pOH = 14.00); report the requested one.
```

**Score: Weak (common_point_loss)**
```

**Score: Full credit (answer_move)**
```
Full credit: (1) NaOH is a Group I hydroxide, so [OH⁻] = 0.010 M. (2) pOH = −log(0.010) = 2.00. (3) At 25°C, pH = 14.00 − 2.00 = 12.00.
```

## 8.3 Weak Acid and Base Equilibria

**Know: core_idea**
```

- B + H₂O ⇌ HB⁺ + OH⁻; Kb = [OH⁻][HB⁺]/[B].
- Conjugate pair: Ka × Kb = Kw; pKa + pKb = pKw.
```

**Know: mechanism (what_students_need_to_understand)**
```
Weak acid, initial versus equilibrium (typically):

| Quantity | Value |

```

## 8.4 Acid-Base Reactions and Buffers

**Know: core_idea**
```
- Strong acid + strong base: H⁺ + OH⁻ → H₂O, quantitatively.
- Weak acid + strong base: HA + OH⁻ → A⁻ + H₂O, to completion.
- Weak acid + weak base: HA + B ⇌ A⁻ + HB⁺, to equilibrium.
```

**Know: mechanism (what_students_need_to_understand)**
```
After a weak acid reacts with a strong base (weak base with strong acid mirrors it):

| What remains | pH from |
| Excess strong reagent | Excess moles ÷ total volume |
| HA and A⁻ both | Henderson-Hasselbalch (buffer) |
| Equimolar | Conjugate-species equilibrium |
```

**Score: steps (how_this_becomes_points)**
```
1. Mole table: with a strong acid or base present, react the limiting reagent completely.
2. Identify the species that remain.
3. Choose the pH method that fits those species.
```

**Score: Weak (common_point_loss)**
```
Weak: “A neutral solution because acid and base reacted.” It skips step 2: weak acid and its conjugate base both remain.
```

**Score: Full credit (answer_move)**
```
Full credit: (1) The strong base reacts completely with the weak acid: HA + OH⁻ → A⁻ + H₂O. (2) HA remains in excess, together with A⁻. (3) Appreciable HA and A⁻ means a buffer forms, so pH comes from Henderson-Hasselbalch.
```

## 8.5 Acid-Base Titrations

**Know: core_idea**
```
- Curve: pH (vertical) versus titrant volume (horizontal).
- Equivalence (monoprotic): moles titrant = moles analyte.
- Half-equivalence (weak): [HA] = [A⁻] (weak base: [B] = [HB⁺]), so pH = pKa.
- Not tested: computing each species' concentration along a polyprotic titration curve.
```

**Know: mechanism (what_students_need_to_understand)**
```
pH at the equivalence point:

| Titration | pH |
| Strong acid–strong base | Neutral |
| Weak acid–strong base | Basic (A⁻ reacts with water) |
| Weak base–strong acid | Acidic (HB⁺ reacts with water) |
```

**Score: steps (how_this_becomes_points)**
```
1. Read the equivalence volume (moles titrant = moles analyte).
2. Halve that volume for a weak acid or base.
3. Read the pH there: it equals pKa (of HB⁺ for a weak base).
```

**Score: Weak (common_point_loss)**
```
Weak: “pKa is read at 20.0 mL because that is the equivalence point.” It skips step 2: pKa is read at half the equivalence volume.
```

**Score: Full credit (answer_move)**
```
Full credit: (1) Equivalence is at 20.0 mL. (2) Half-equivalence is 20.0 ÷ 2 = 10.0 mL. (3) There [HA] = [A⁻], so pH = pKa.
```

## 8.6 Molecular Structure of Acids and Bases

**Know: core_idea**
```
- Strong acids have very weak conjugate bases; strong bases have very weak conjugate acids.
- Conjugate-base stabilizers: electronegativity, inductive effects, resonance.
- Common weak acids: carboxylic acids. Common weak bases: nitrogen bases (e.g. NH₃), carboxylates.
```

**Know: mechanism (what_students_need_to_understand)**
```
Acid strength follows conjugate-base stability, other things equal:

| Conjugate base | Acid |
| More stabilized | Proton loss easier: stronger |
| Less stabilized | Proton loss harder: weaker |
```

**Score: steps (how_this_becomes_points)**
```

2. Identify what stabilizes it: electronegativity, inductive effect or resonance.
3. Link: more stable conjugate base, more favorable proton loss, stronger acid.
```

**Score: Full credit (answer_move)**

Full credit: (1) Look at the conjugate base left after proton loss. (2) Resonance spreads its negative charge, stabilizing it. (3) Proton loss is then more favorable, so the acid is stronger.

## 8.8 Properties of Buffers

**Know: core_idea**
```
- Buffer: large concentrations of both members of a conjugate pair, HA and A⁻.
- Added base reacts with HA: HA + OH⁻ → A⁻ + H₂O.
- Added acid reacts with A⁻: A⁻ + H⁺ → HA.
```

**Know: mechanism (what_students_need_to_understand)**
```
Why the pH barely moves:

- Each reaction converts one member into the other, so [A⁻]/[HA] changes only slightly.
- Large amounts relative to the stress keep the ratio, and the pH, nearly constant.
```

**Score: steps (how_this_becomes_points)**
```
1. Name the conjugate acid and conjugate base present.
2. State which one reacts with the added stress.
3. Give the product and why the pH change is small.
```

**Score: Weak (common_point_loss)**

Weak: “HA resists added acid by reacting with it.” It skips step 2: the acid member HA neutralizes added base; added acid reacts with A⁻.
```

**Score: Full credit (answer_move)**
```
Full credit: (1) HA is the conjugate acid and A⁻ the conjugate base. (2) Added H⁺ reacts with A⁻: A⁻ + H⁺ → HA. (3) A⁻ is converted to HA, so the ratio and pH change little.

## 8.9 Henderson-Hasselbalch Equation

**Know: core_idea**
```
- pH = pKa + log([A⁻]/[HA]).
- pH = pKa when [A⁻] = [HA].
- Not tested: derivation of the equation; computing the pH change after acid or base is added to a buffer.
```

**Know: mechanism (what_students_need_to_understand)**
```
pH compared with pKa:

| pH vs pKa | [A⁻]/[HA] |
| Above | Greater than 1 (base form exceeds acid form) |
| Equal | 1 |
| Below | Less than 1 (acid form exceeds base form) |
```

**Score: steps (how_this_becomes_points)**
```
1. Substitute pH and pKa: log([A⁻]/[HA]) = pH − pKa.
2. Raise 10 to that power: [A⁻]/[HA] = 10 to the power (pH − pKa); log base 10, no sign flip.
```

**Score: Weak (common_point_loss)**
```
Weak: “[A⁻]/[HA] = 0.10, because the acid is stronger.” It breaks step 2: the sign is flipped; pH above pKa gives a ratio above 1.
```

**Score: Full credit (answer_move)**
```
Full credit: (1) log([A⁻]/[HA]) = pH − pKa = 1.00. (2) [A⁻]/[HA] = 10¹·⁰⁰ = 10.
```

## 8.11 pH and Solubility

**Know: core_idea**
```
- Solubility is pH-sensitive when a salt's ion is a weak acid, a weak base or hydroxide.
- Reasoning is qualitative, using Le Châtelier.
- Not tested: computing solubility as a function of pH.
```

**Know: mechanism (what_students_need_to_understand)**
```
pH-sensitive salts:

| Salt contains | Effect of added acid (H⁺) |
| Basic anion or OH⁻ | H⁺ consumes it: solubility increases |
| Weak-acid or weak-base ion | Depends: does H⁺ or OH⁻ remove that ion? |
```

**Score: steps (how_this_becomes_points)**

2. Decide whether H⁺ or OH⁻ removes one dissolved ion.
3. If so, Q falls below Ksp and more solid dissolves.
```
